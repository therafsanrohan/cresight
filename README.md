# CRESIGHT

Premium Creative Agency Frontend Application.

## Overview
A world-class, premium digital experience built for CRESIGHT. This application serves as the core digital presence for the brand, utilizing a minimal, sophisticated, and highly performant architecture.

## Tech Stack
- Framework: Next.js (App Router)
- Language: TypeScript
- Styling: Tailwind CSS
- Animation: Framer Motion

## Getting Started

1. Install dependencies:
\`\`\`bash
npm install
\`\`\`

2. Run the development server:
\`\`\`bash
npm run dev
\`\`\`

3. Build for production:
\`\`\`bash
npm run build
\`\`\`

## Design System
The application utilizes a strict monochrome color palette:
- Deep Black: `#050505`
- Soft White: `#F5F5F3`
- Light Gray: `#CFCFCF`
- Graphite: `#1B1B1B`

Typography is primarily handled by Helvetica Neue, designed with an editorial, magazine-inspired spacing structure.
